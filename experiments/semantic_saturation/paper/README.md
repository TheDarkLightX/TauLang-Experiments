`QUALITY_TABLES.md`, `quality-display-data.json`, and `figures/` provide source-bound quality displays. Rebuild them with `python3 experiments/semantic_saturation/paper/build_quality_figures.py` from the repository root. The script reads completed evidence and writes only this paper directory. `native-parser-sensitivity.json` records the post-hoc attribution sensitivity without changing primary outcomes.

`build_parser_sensitivity.py --check` checks the post-hoc diagnostic against all completed raw rows; without `--check` it regenerates the paper-local diagnostic and provenance sidecar. The raw quality rows used by the quality and sensitivity scripts are preserved as archive entries in `../evidence/heldout-001.tar.gz`; extract that archive into the study directory before those rebuilds if the raw result tree is absent. The reuse figure builder uses the flattened public summary, verification, and analysis files and requires no raw archive extraction.

Public per-stream reuse tables and exact curve data are linked from the manuscript under `../results/reuse-001-ANALYSIS.md`, `../results/reuse-001-costs-and-break-even.csv`, and `../results/reuse-001-summary.json`. The full raw reuse records are stored losslessly in four ordered byte parts. Follow [ARCHIVE_PARTS.md](../evidence/ARCHIVE_PARTS.md), running `python3 experiments/semantic_saturation/evidence/reconstruct_reuse.py` from the repository root before reuse archive extraction. The helper verifies each part and the complete concatenation and restores the original `../evidence/reuse-001.tar.gz` bytes; it refuses to overwrite different content or a symlink.

`build_reuse_figures.py` regenerates cold-inclusive curves for the eight workload mixtures, retaining three repetitions and separating context-safety controls. `build_pdf.py` uses Pandoc to parse Markdown and ReportLab to typeset the manuscript and original figures. Generated build intermediates remain ignored under `.build/`.
